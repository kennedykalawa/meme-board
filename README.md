# 🎭 Meme Board - Let's Make Some Memes!

This is my meme generator project! All you gotta do is paste an image link and add some funny text. This is gonna be fun 😁

## 🚀 How to Use It

1. Open up `index.html` in your browser
2. Copy any meme image link from the internet
3. Type your top text (the setup)
4. Type your bottom text (the punchline!)
5. Click "Generate Me" and boom! Your meme is ready 🎉
6. Don't like a meme? Just click on it to delete it

## What I Built

So basically I made this cool generator where you can:
- Paste any image URL and turn it into a meme
- Add text at the top and bottom (classic meme style!)
- See all your memes in a gallery
- Delete the ones you don't like by clicking on them
- The text has that cool black outline like real memes

## The Cool Stuff

I used the **Anton font** for the meme text because it looks super dramatic and meme-y 😄

My color scheme is **aqua and dark gray** - I really like how it looks, kinda modern and fun.

When you hover over a meme, it shows a red overlay that says "Click to Remove 🗑️" so you know you can delete it.

## 🎨 My Design Choices

- **Background**: Dark gray (`rgb(45, 45, 45)`) because dark mode is the best
- **Accent color**: Aqua because it pops and looks awesome
- **Meme font**: Anton - super bold and perfect for memes
- **Button**: Says "Generate Me" because "Generate" alone is boring 😉
